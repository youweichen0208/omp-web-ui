# pi-harness · 对话与代码改动 设计文档

定稿：**35a**。设计图来自用户提供的 `页面重设计优化 (23).zip` 内 `chat-diff-design.html`，可以切换五种状态：默认、展开命令组、文件列表、文件收起、关闭改动面板。
本方案对应对话页，以及新增的「代码改动」面板。命令组（27a / 29a / 30a）、输入框（28a）、等待指示器（31a）的规则继续生效，本文只写新增和变化的部分。

---

## 1. 目标

- **左边读过程，右边看改动**：对话里只保留 pi 说的话和关键步骤，具体的代码改动集中放到右侧面板。
- **历史可以收起，当前可以展开**：已经过去的工具调用只留一行，正在进行的这一轮可以展开看。
- **改过的文件一点就能看到**：从对话里的文件卡片，到右侧 diff 的对应位置，一步直达。

## 2. 布局

```
┌ 对话列 600px ───────────────────────┬ 改动面板（自适应，最小 560px）──────────────────┐
│ 顶栏 48px：▯ 标题 ⌄ [分支] … [改动 +47 −28] ⋯ │ 顶栏 48px：≡ develop → 分支 ⌄ [本轮|整个分支|未提交] ⌕ ⇕ ✕ │
│ 消息流（内容最宽 620px，居中）          │ [文件列表 200px] │ 按文件分段的 diff         │
│ 输入框                                │                  │                          │
└ 状态栏 26px ───────────────────────────────────────────────────────────────────────┘
```

| 状态 | 列宽 |
|---|---|
| 改动面板打开 | 对话 600px / 面板自适应；项目栏自动收起 |
| 改动面板关闭 | 对话占满，内容仍然最宽 780px，居中 |
| 文件列表打开 | 面板内部是文件列表 200px / diff 自适应 |

- 窗口宽度小于 1200px 时，改动面板改成浮在对话上方的抽屉，宽 min(720px, 90vw)。
- 面板打开时，左侧项目栏自动收起；关闭面板后恢复。用户手动展开项目栏时，以用户的操作为准。
- 改动面板用白底，对话列用 `--bg`，两者之间是 1px 分隔线。

## 3. 对话列

### 3.1 顶栏（48px）
- 左边：项目栏开关（28px 图标按钮）、对话标题（600 字重）⌄、分支标签（6px 圆角浅灰底，12px）。
- 右边：
  - **改动按钮**：图标加「改动」，后面是 `+47`（绿）和 `−28`（红），用等宽字体 11.5px。面板打开时，按钮用 `--accent-soft` 底、`--accent` 字。快捷键 ⌘D。
  - ⋯ 更多。
- 没有任何改动时，改动按钮不显示。

### 3.2 历史步骤：收成一行
已经过去的工具调用组（这一轮之前的，或者 pi 已经说过话之后的）只占一行：

```
✓ 查看 PR 状态 · 3 条命令 ›
```

- 13px，`--text-dim`。✓ 用 `--green`；如果组里有失败，改成 ✗ 加 `--red`，后面写「· 1 条失败」。
- **标题**：用 pi 在这组调用之前说的那句话（30a 的规则）。没有说话时，用第一条命令的 echo 标题，或者自动生成的说明。
- 点击后原地展开成 27a 的命令组卡片，箭头变成 ⌄。
- 当前这一轮正在运行的命令组默认展开；这一轮结束后自动收成一行。

### 3.3 回复正文
- 13.5px，行高 1.75，正文颜色。行内代码用浅灰底、等宽字体。
- 提到 PR、文件路径时显示成链接：PR 显示成 `#25` 标签，文件路径点击后在改动面板或文件预览中打开。

### 3.4 改动汇总卡（一轮结束时）
回复末尾附一张卡片，列出这一轮改过的文件：

```
┌───────────────────────────────────────────┐
│ 改了 4 个文件  +47 −28            全部查看 │  ← 浅灰底
├───────────────────────────────────────────┤
│ ▢ v1.0.0.md   .github/release-notes  +10 −6 › │
│ ▢ legacy-service-test.mjs  tests     +16 −21 › │
│ …                                          │
└───────────────────────────────────────────┘
```

| 部分 | 规格 |
|---|---|
| 卡片 | 白底，1px `--border`，圆角 `--r-md` |
| 头部 | `oklch(0.98 0.003 80)` 底，12.5px；右侧「全部查看」用 `--accent` |
| 文件行 | 16px 线框文件图标 · 文件名（等宽 12.5px）· 目录（12px 灰色，超出部分用省略号）· `+N −M` · › |
| 选中 | 当前在面板里显示的文件，行底色 `oklch(0.96 0.015 240)`，文件名 600 字重 |

- 只列这一轮**成功**写入或修改的文件，规则和右栏「输出」一致。
- 点击文件：打开改动面板（如果关着），选中这个文件，如果它被收起了就展开，并滚动到它。
- 「全部查看」：打开面板，展开全部文件，滚到第一个文件。
- 超过 6 个文件时，只显示前 6 个，下面加一行「还有 N 个文件」。

### 3.5 消息底部
- 一行 12px 灰字：复制 · 重新生成 · 时间。只在最后一条回复下面一直显示，其他回复悬停时才显示。

### 3.6 输入框（沿用 28a）
- 底部一行：＋ · 模型 ⌄ · 思考 ⌄ ·（运行中时显示插话/排队 ⌄）· **上下文 N% · 缓存 N%** · ■ · ↑
- 「上下文 N% · 缓存 N%」是一段灰字，悬停时显示「上下文窗口用量 · 缓存命中率」，点击打开用量弹窗。
- 缓存还没有数据时只显示上下文；数值为 0 时整段隐藏；输入框不超过 530px 时隐藏缓存，弹窗里仍然可以看到。

## 4. 改动面板

### 4.1 顶栏（48px）

| 位置 | 内容 |
|---|---|
| ≡ | 打开或关闭文件列表；打开时浅蓝底 |
| 分支 | `develop`（灰色等宽字体）→ `当前分支`（等宽，超出部分用省略号）⌄；下拉里可以换基准分支 |
| 范围 | 分段切换：**本轮**（默认）/ 整个分支 / 未提交 |
| 右侧 | ⌕ 在改动里搜索 · ⇕ 全部展开或收起 · ✕ 关闭（⌘D） |

**范围**
- **本轮**：只显示这一轮 pi 改过的文件和行，和汇总卡一致。
- **整个分支**：显示基准分支到当前分支的全部差异（`git diff base...HEAD`）。
- **未提交**：显示工作区和暂存区的改动（`git diff HEAD`）。
- 非 Git 项目只有「本轮」，范围切换不显示。

### 4.2 文件列表（200px）
- 背景 `oklch(0.985 0.003 80)`，右边 1px 分隔线。
- 顶部 11.5px 灰字：「4 个文件 · +47 −28」。
- 每一项占两行：第一行是文件名（等宽 12px）；第二行是目录（灰色）和 `+N −M`。
- 当前文件：`oklch(0.93 0.004 80)` 底，文件名 600 字重。
- 点击后滚动到对应文件，并同步选中汇总卡里的同一行。

### 4.3 文件段
每个文件一段，段与段之间是 1px 分隔线。

**文件头**（38px，滚动时固定在顶部）

```
⌄  v1.0.0.md  .github/release-notes  +10 −6                    打开文件 ↗
```

- 背景 `oklch(0.985 0.003 80)`；当前选中的文件用 `oklch(0.97 0.012 240)`。
- 点击文件头可以收起或展开这一段。
- 「打开文件 ↗」：在文件预览或编辑器里打开，并定位到第一处改动。

**diff 行**

| 部分 | 规格 |
|---|---|
| 色条 | 最左边 3px：新增行 `--green`，删除行 `--red`，未改动的行透明 |
| 行号 | 44px，右对齐；新增行用新文件行号，删除行用旧文件行号；颜色跟随类型，未改动的行用浅灰 |
| 符号 | 18px，`+` 或 `−` |
| 内容 | JetBrains Mono 12.5px，行高 1.75；`white-space: pre-wrap`，长行自动换行 |
| 行底色 | 新增行 `--green-soft`，删除行 `--red-soft` |
| 词级高亮 | 一行里真正改动的词再深一档：新增 `oklch(0.86 0.08 150)`，删除 `oklch(0.88 0.06 25)`，圆角 2px |
| 语法色 | 保持克制：Markdown 标题用 `--accent`，其他保持正文颜色 |

**折叠行**
- 连续 4 行以上没有改动时，折成一行「⇕ N 行未改动」：30px 高，`oklch(0.975 0.003 80)` 底，12px 灰字。
- 点击后展开全部；改动前后各保留 3 行上下文。
- 文件末尾写「显示后面 N 行」。

**大文件**
- 单个文件改动超过 400 行时，默认收起，文件头后面加「大文件 · 点击展开」。
- 二进制文件只显示文件头和「二进制文件，无法显示差异」。
- 重命名的文件，文件头写成「旧名 → 新名」。

### 4.4 颜色

| 用途 | 变量 |
|---|---|
| 新增 | `--green` #3E9B5F / `--green-soft` #E6F4EA |
| 删除 | `--red` #C9483A / `--red-soft` #FBE9E7 |
| 选中、链接、开关 | `--accent` #2F7AAE / `--accent-soft` #EAF2F8 |

面板里**不用**紫色，也**不用**整块深色代码区；深色模式下换成对应的深色变量。

## 5. 交互和快捷键

| 操作 | 结果 |
|---|---|
| ⌘D / 顶栏改动按钮 | 打开或关闭改动面板 |
| 汇总卡里点文件 | 打开面板，选中并滚动到这个文件 |
| 面板里滚动 | 文件列表和汇总卡同步高亮当前文件 |
| ⌘F（焦点在面板时） | 在改动里搜索 |
| J / K（焦点在面板时） | 跳到下一处 / 上一处改动 |
| Esc | 关闭搜索；再按一次把焦点还给输入框 |

- 面板的打开状态、文件列表的开关、范围选择，按对话记住。
- pi 运行时，面板实时更新：新改的文件追加到列表末尾，文件头后面短暂显示「刚刚改动」黄点，持续 3 秒。

## 6. 数据来源

- **本轮**：用当前任务里成功的 `edit` / `write` 工具结果，按规范化后的路径合并，按工具 ID 去重。增删数只用可靠的 diff 统计（和右栏「输出」相同）。
- **整个分支 / 未提交**：服务端执行 git diff，返回统一 diff 格式；词级高亮在前端计算（逐行配对后做词级比较）。
- SDK 没有返回 diff 的成功编辑：根据替换参数显示改动的行，文件头注明「行号不可用」。

## 7. 不再出现

- 历史工具调用展开成整张卡片，铺满对话。
- 对话里的整块深色 diff。
- 每次编辑都单独显示一张 diff 卡片（改成在汇总卡和面板里统一查看）。
- 「已运行 33 个命令，已编辑 xxx」这种把命令和文件混在一行的写法：命令收成一行，文件放进汇总卡。

## 10. 待确认

- 改动面板要不要支持左右并排的 diff 视图（宽屏下可选）。
- 汇总卡在多轮对话里是每轮都出现，还是只在最后一轮出现。
- 「整个分支」范围的默认基准分支：用仓库默认分支，还是创建这个分支时所在的分支。

## 实施决策

- 使用统一 diff；并排视图保留为后续可选项。
- 每个已完成用户轮次生成汇总卡；自动提醒留在原轮次。当前轮次使用服务端 taskProgress 的同一份成功输出统计。
- 基准优先使用 origin/HEAD，然后依次检查 main、master、develop，最后 HEAD；用户可以选择其他本地或远程分支。
- 新增 scm_diff 只读消息，协议 v41；Git 查询关闭外部 diff 和 textconv，解析 ref 后构造 merge-base 范围。未提交包括未跟踪文件，文本预览最多 512 KiB，总 diff 最多 16 MiB。
- 本轮写入没有旧内容时不推断删除行或变更统计；替换参数回退明确显示“行号不可用”。
- 面板偏好按对话保存在标签页 sessionStorage；选择历史汇总后展示该轮记录，点击“本轮”返回实时输出。
