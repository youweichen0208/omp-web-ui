# 工作区界面规范（当前状态）

> 本文只描述**现在应该是什么样**。历史版本和被替代的规则移到 `docs/history/ui-design-changelog.md`。
> 修改界面时先改本文，再改代码；本文与代码冲突时，以本文为准，并修正代码。

---

## 1. 设计令牌

所有颜色和圆角只能通过 CSS 变量使用，组件里不写十六进制颜色（终端 ANSI 调色板和第三方渲染器配置除外，见 1.4）。

### 1.1 颜色

| 变量 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--accent` | `#2F7AAE` | `#5BA3D6` | 选中状态、链接、开关、可以点的发送按钮、当前对话圆点、选中文件左边的竖条 |
| `--accent-soft` | `#EAF2F8` | `#203E52` | 开关打开时的底色（如「π 对话」按钮） |
| `--green` / `--green-soft` | `#3E9B5F` / `#E6F4EA` | `#79C68E` / `#243C2B` | 完成、成功 ✓、diff 新增行 |
| `--red` / `--red-soft` | `#C9483A` / `#FBE9E7` | `#EF9689` / `#452B29` | 失败、中断 ✗、diff 删除行、危险操作 |
| `--yellow` | `#F2BC4E` | `#EDC765` | 进行中的圆点 |
| `--yellow-fg` / `--yellow-bg` | `#8A5A00` / `#FDF1D6` | `#EDC765` / `#463C22` | 改动数、待发标签、「工作中」文字 |
| `--bg` | `#FBF9F6` | `#1C1C1B` | 窗口背景 |
| `--bubble-bg` | `#F1EEEA` | `#33322E` | 用户消息气泡 |
| `--output-bg` | `oklch(0.97 0.003 80)` | `#292926` | 命令输出、代码块 |

**规则**
- 一种颜色只有一个含义：蓝色表示选中或链接，绿色表示成功，红色表示失败，黄色表示有改动或进行中。
- 界面不使用紫色。珊瑚色 `#EE8C7C` 只出现在图标和等待指示器的方块里。
- 同一个改动数只显示在两处：顶栏 Git 后面和目录树里，用黄色。文件栏标题里的「改动 N」用中性灰。
- 每个变量只定义一次：浅色在 `:root`，深色在 `:root[data-appearance="dark"]`，不在后面重复覆盖。

### 1.2 圆角

| 变量 | 值 | 用于 |
|---|---|---|
| `--r-sm` | 6px | 按钮、图标按钮、列表项、标签 |
| `--r-md` | 8px | 输入框、卡片、代码块、命令组 |
| `--r-lg` | 12px | 弹窗、设置窗口 |

圆点状态指示使用 50%；开关轨道使用 `--r-switch`，等待方块使用 `--r-waiting`（1.5px，见 4.4）。词级 diff 高亮使用 `--r-diff-word`（2px，内容专用）。其余圆角使用上表三个令牌；`0` 用于直角，`inherit` 只用于继承父元素圆角。

### 1.3 字体
- 界面和正文用 IBM Plex Sans，中文优先用本地 UI SC（Noto Sans SC 子集，400/500/600）；生僻字回落到 PingFang SC／Microsoft YaHei。子集包含 GB2312 一级字和前端源码中的汉字、标点。
- 命令、路径、版本号、代码用本地 JetBrains Mono，关闭连字；依次回落到 Cascadia Mono、SF Mono、Menlo、Consolas。
- 正文 13–13.5px，行高 1.7；辅助文字 12px；状态栏 11px。

### 1.4 允许写死颜色的地方
- 终端 ANSI 调色板（`--term-*`，光标使用 `--accent`）。
- Mermaid 等第三方渲染器配置读取 CSS 变量。独立代码配色（`--file-code-*`、`--wiki-code-*`、`.hljs-*`）可以定义内容色板，关键字使用蓝色系。
- 文字高亮色板（`remark-text-highlight` / `.fp-highlight-*`）。这是用户可选的内容颜色，不属于界面颜色。
- 系统关闭按钮悬停红色（`.desktop-window-close:hover`）。深色浮层及阴影统一读取根变量。
- 深色命令输出中的 Git 状态使用 `--out-green`、`--out-yellow`、`--out-red`，与界面状态色分开。

`npm run check:design` 扫描 `web/src` 下全部 `.css`、`.ts`、`.tsx`，禁止色板及上述例外之外的十六进制颜色、RGB/HSL、颜色名和紫色 OKLCH；非令牌圆角报错并给出行号。颜色名只检查样式值，避免误报文案、路径和标识符。透明色与 `currentColor` 可用。图片转码的白底和文档高亮序列化色板属于内容处理，检查只豁免对应文件中的指定声明。`npm test` 先运行此检查。根色板只允许根选择器中的变量声明，不能通过带 `data-appearance` 的组件规则绕过检查。

---

Windows 浅色界面在 React 渲染前设置 data-platform，正文字号按原基准增加 0.5px，次要文字使用 Windows 专用根令牌。浅色非终端滚动区默认隐藏滑块，悬停显示 8px 轨道中的 4px 滑块；拖动颜色加深。xterm 与深色模式沿用原样式。Electron 启动背景与暖白窗口一致。

## 2. 图标与品牌
- 侧栏 logo 24px，顶栏和 pi 头像 18px，统一使用 `1a-flat.svg`，不加底板。
- favicon 用 32px PNG，Apple touch icon 用 180px PNG。
- 产品界面的 emoji 图标统一改为 16px、stroke-width 1.5、currentColor 的线条 SVG；用户消息和文档原文不替换。

## 3. 布局

### Workspace 项目分组（#53）

左栏品牌下只显示 Workspace 选择器与管理入口，不再显示“全部项目”或顶部“新对话”按钮。首次没有 Workspace 时显示创建表单与空态，不展示旧最近目录或历史会话；不删除磁盘目录、历史文件或服务端最近记录。创建分组后从空列表开始，用户手动添加项目。选择器只包含已有分组，优先恢复上次选择，选择失效时回到第一个分组；删除最后一个分组后恢复创建空态。

选择分组只筛选项目列表，不切换当前对话或 Agent 工作目录。当前项目不在分组时，显示“当前对话在此分组外”和“加入当前项目”按钮。添加项目通过目录选择器登记目录，不切换会话；点击项目仍走原有项目切换和未保存编辑保护。项目菜单支持从当前分组移除，当前项目菜单保留新对话操作；键盘新对话仍沿用当前项目。管理表单支持创建、重命名和二次确认删除分组，同一项目可属于多个分组。搜索仅查当前分组，空分组和无搜索结果显示明确空态。

保存期间禁用重复操作，失败保留编辑内容并显示错误；多窗口发生过期修改时刷新分组并要求用户重试。移动端管理操作保留左栏抽屉。原有会话、目录和 Agent 配置不随分组改变。

- 左栏 264px，可以拖动调整宽度和收起；右栏 272px，可以拖动调整宽度和收起。
- 对话内容和输入框最宽 780px，居中。
- 顶栏 44px，用下划线页签，当前页签加粗并显示蓝线。
- 状态栏 32px，显示连接状态 · 版本 · 分支 · 路径，不显示消息数。
- 宽度 ≤1100px 时，文件栏变成抽屉；≤768px 时，用移动端抽屉。

### 流畅界面（Web / Desktop 共用）

保留暖色底、蓝色操作强调和 pi 图标，沿用正文及代码字体。导航使用较厚的半透明材质，正文保持实色；弹窗、菜单使用更轻的浮层与统一阴影。标题以字重和微调字距建立层级，辅助标签保持清晰对比。顶栏仍为 44px，不改变 Electron 原生窗口按钮避让和可拖动区域。

按钮按下立即反馈，不等待请求完成；键盘焦点使用明确轮廓。移动端侧栏和窄屏文件抽屉使用可中断、携带当前速度的临界阻尼弹簧，进出沿同一路径。抽屉顶部专用拖动区支持指针捕获、速度投射和边界阻尼，正文滚动不被手势接管；关闭按钮和 Escape 均可关闭，隐藏抽屉不可获得焦点。宽屏面板宽度拖动保持 1:1，支持取消和键盘方向键调整。

减少动态效果时抽屉直接到位、浮层静态显示；减少透明度或提高对比度时使用实色背景和清晰边框。动画仅改变 transform/opacity，不给文本流添加入场位移，不循环播放装饰动画。

## 4. 对话流

通知：同一对话、级别和正文完全相同的可见通知合并为一条，以「×N」显示出现次数；不同对话的通知独立。重复信息通知刷新自动关闭计时，警告与错误保留到手动关闭。

### 4.1 消息
- 用户消息：靠右，`--bubble-bg`，圆角 8px，最宽 75%。
- pi 回复：先是一行头部（18px logo · pi · 时间），正文不加气泡，和工具卡片左对齐在同一列。
- 过程说明：工具调用前后的短句（少于 40 字，说的是下一步要检查、读取或修改什么），用 12.5px 灰字。结论和要点保持正文样式。
- 长历史摘要每组保持单行：角色、正文预览、时间和展开箭头。工具次数、思考和附件统计放在悬停说明，不再单独占一行；没有正文时用统计作为摘要。整行可点击或键盘展开，完整内容与搜索定位保留。
- 长历史的折叠摘要也参与惰性窗口化，首次加载先用等高占位；视口附近才挂载摘要。占位保留消息定位，搜索、展开与问题跳转仍可恢复完整内容。

### 4.2 命令组（27a / 29a）
- 连续的 bash 调用合成一组。组标题写「运行了 N 条命令」，有失败时再加「· N 条失败」。只有 1 条命令时不显示组标题。
- 每条命令一行：
  - 如果命令带 `echo "=== 标题 ==="`，就用这个标题当名字，后面跟灰色等宽字体的真实命令（单行，超出部分截断）。
  - 可以识别的 `sed -n` 读取，显示文件名和行号范围。
- 去掉开头的 `cd 项目目录 &&` 和结尾的 `2>/dev/null`。展开、复制和重跑都使用完整的原命令。
- 标题相同的连续命令合成一行，标「试了 N 次」，显示最后一次的命令和结果。
- 输出默认收起，失败的那一条自动展开。输出最多显示 6 行，带行号，用 `--output-bg` 底色。
- 组内只显示最后 8 条，上面显示「展开全部」。
- 不到 1 秒不显示用时；没有实测数据时显示「耗时未记录」。

### 4.3 文件改动（35a）
- 对话与代码改动遵循 [35a 设计](chat-diff-design.md)。成功改动在每轮汇总卡与独立 ChangesPanel 中显示；失败和运行中的调用保留状态。历史命令组默认收为一行，当前运行组展开。
- 面板默认本轮，支持整个分支与未提交；600px 对话列，面板最小 560px；1200px 以下使用抽屉。
- 以下旧卡片规则只用于失败详情及兼容视图。
- 标题行：操作 · 文件路径 · `+N −M` · 状态。
- diff 在浅色模式下：新增行用 `--green-soft` 底，删除行用 `--red-soft` 底，行号那一栏颜色再深一档。深色模式下用对应的深色变量。
- 相邻 3 次及以上的编辑合成一个文件列表，每个文件的 diff 默认收起。

### 通用工具卡片（#45）
- 自定义/MCP 工具使用紧凑标题行：工具图标、可点击折叠的名称、状态与耗时；放大和复制参数使用带可访问名称的图标按钮。
- 简短标量参数按键值展示，复杂参数保留可滚动原文；输入区明确标为「参数」，输出区保持既有截断与展开行为。
- 完整输出下载位于卡片底部的轻量操作区，不使用突兀的默认按钮。没有文本但有输出文件时说明可下载完整结果，不展示空输出框。
- Bash、文件读取、编辑和 Codemode 专用卡片保持各自布局。窄屏标题允许名称截断，参数自动换行，所有操作可键盘访问。

### 4.4 等待指示器（31a）
- 三个 6×6px 方块（`#EE8C7C` `#3E8FC0` `#F2BC4E`），圆角 1.5px，间距 3px，依次呼吸，周期 1.2s。
- 文字 13px，字重 500，灰色加流光（1.8s）；用时 12px 灰字。
- 位置：最后一个内容下方 8px，左边留 2px。
- 聊天运行状态文案固定使用英文（包括中文界面），计时用 sec/min，停止按钮为 Stop：

| 阶段 | 文案 |
|---|---|
| 刚发出消息 | Understanding your question |
| 工具调用刚结束 | Reading command results / Reading files |
| 有思考但还没有正文 | Thinking |
| 测试或构建命令超过 4 秒 | Waiting for test results / Waiting for build results |
| 插话已送达 | Processing your direction |

- 300ms 后才出现；4 秒后显示用时；60 秒以上显示「M min SS sec · Stop」。
- 收到正文或思考内容时立刻消失。断线、重试、压缩或静默告警时由对应的状态接管。
- 系统开启减少动态效果时，方块和文字都静止。
- **不再使用**：「正在分析请求」「仍在思考」「响应较慢」「等待模型」，以及显示在标题行的蓝色等待状态。

### 4.5 工具调用未执行（33a）
- 完整交互与验收见 [33a 设计说明](tool-unexecuted-design.md)，取代 32a。
- 每次用户请求最多自动提醒一次；同一次异常用稳定 incidentId 关联，真实工具调用后恢复正常。
- 首次漏出调用只留灰色说明；自动提醒显示居中事件行，跳过问题导航、编辑和折叠摘要。
- 最终停住只在最后回复后显示一张白底、浅红标题的恢复卡，原文按尝试次数集中展示。
- 换模型使用可键盘操作的自定义菜单，重发原始问题及其附件。
- 自动提醒中三栏统一黄色工作中；最终停住统一红色中断，无计划时显示说明代替空状态。
- 空 system 消息不渲染；离底部超过一屏才显示回到底部；上下文与缓存为零时隐藏。

## 5. 输入框（28a）
- 文件拖放结束、取消或窗口失焦后立即清除窗口遮罩；输入框等子区域独立接收文件时也必须清除。
- 圆角 8px，描边 `oklch(0.88 0.005 80)`。只有聚焦且有内容时，描边才变成 `--accent`，不加外部光晕。
- 底部一行依次是：附件 · 模型 ▾ · 思考 ▾ · 插话/排队 ▾（只在运行中显示）· 上下文 N% · 缓存 N% · ■ · ↑。
- 图标按钮 28×28px，圆角 `--r-sm`：
  - ↑ 发送：没有输入时是灰色，不能点；有输入时是 `--accent` 底、白色箭头。
  - ■ 停止：只在运行时显示。白底、描边，中间是深色方块；悬停时变成 `--red-soft` 底、`--red` 方块。
- 快捷键：↵ 按选中的方式发送，⌥↵ 用另一种方式，⇧↵ 换行。Esc 在有文字时清空，空输入时停止。
- 待发消息固定在输入框上方，只占一行：黄色标签 · 摘要（超出部分用省略号）· 撤回。
- 宽度不够时：先缩短模型名，输入框 ≤530px 时隐藏缓存摘要，按钮不缩小。

## 6. 右栏
- 目录已删除、无权限或不可读取时，在对应树节点下显示原因和刷新按钮，不弹出重复通知；根目录失效提示重新选择项目。刷新成功清除错误。
- 文件标题栏提供新建文件与刷新按钮；新建在标题下输入工作区相对路径，父目录需已存在，创建空文件后打开，重名报错并保留输入。刷新保留展开状态并更新已展开目录。Wiki 文件栏共用新建入口，默认填入当前文档所在目录。
- 上半部分是文件树，下半部分是「进度 / 输出」双分区卡片，两区可以分别折叠。
- **进度**：只显示原生 plan 的步骤，不从工具调用推测步骤。本轮已采用计划的当前步骤用 `--accent`；尚未用于本轮的历史计划中，未完成步骤统一显示待办，不高亮或自动滚动到历史当前项。完成用 `--green` ✓，失败或中断用 `--red`。历史计划仅显示「此前未完成计划」，不提示用户确认；计划工具不引入单独的审批步骤。
- **输出**：只列当前任务里成功 write/edit 的文件，每个文件显示 `+N −M`。
- 不显示命令记录、读取记录、「计划有变」提示或总耗时。

## 7. Wiki（34a）
- 文件栏和对话面板提供可聚焦拖动手柄，记忆各自宽度；方向键以 10px 调整，双击或 Home 恢复默认。窄屏文件抽屉保持固定宽度，手柄隐藏。Windows/Linux 的 Wiki 顶栏始终为窗口控制按钮预留 148px，对话开关不被遮挡。
- 索引未完整时才显示黄色状态「已索引 N / M · 跳过 K」，数字带千分位；未统计完的总数显示「统计中」，不用 +。原因放悬停提示和详情，详情逐类统计。
- 面包屑只显示项目相对目录，空间不足中间省略、悬停显示完整路径；对话按钮距窗口右缘至少 16px。树行 30px，文件预留箭头宽度，与同级目录名对齐。
- 标题信息到正文 28px，段落间距 .75em；开头连续的字段/值作为可折叠的 12.5px 属性表，保留 Markdown 原文。输入框禁止手动缩放。表格图标带表头，引用图标用左竖线，宽版用横向双箭头。
- 文档页以 [Wiki 文档页 v2](wiki-doc-v2-design.md) 为准：默认直接编辑，独立 44px 插入栏，标准正文 760px、宽版 1000px。H1/H2 使用本地衬线子集；保存状态位于顶栏。
- 明确的 `./`、`../` 文件链接可直接打开未参与后台索引的知识证据；服务端仍校验工作区真实路径，缺失文件显示读取错误，模糊双链继续要求索引中的唯一匹配。
- 已登记知识目录的 evidence 快照在 Wiki 中只读，知识正文继续使用现有编辑与保存流程。
- 工具栏与 `/` 共享全部 11 个插入项，按正文、H2、H3、列表、表格、图片、任务列表、引用、代码块、文档链接、日期排序，全部直接显示，不再使用「＋」菜单；标题按钮分别设置固定级别，窄栏横向滚动；表格 8×6 尺寸格，代码语言含 Mermaid，渲染图表并保留源码。
- 目录选中项使用暖灰底，不显示文件图标或蓝色竖条。标题元信息显示日期、阅读时长和标签。
- 表格尺寸格和行内代码分别使用 `--r-wiki-grid`（3px）、`--r-wiki-code`（4px），为文档内容专用令牌。
- 文档正文最宽 760px（宽版 1000px），两侧各 64px 留白；左栏 250px，对话面板 400px。
- 顶栏用「对话 | Wiki」两段切换；按钮和开关的选中状态用 `--accent-soft` 底加 `--accent` 字。
- 底部及对话面板输入框共用一处基础样式：圆角 `--r-md`、`--input-border` 描边、无光晕；仅聚焦且有非空白文字时用 `--accent` 描边。对话面板只覆盖布局与内边距。发送按钮用 `--r-sm`。
- Wiki 代码配色跟随应用外观，浅色和深色色板分别在根变量中定义一次；不再使用独立 `data-code-theme` 覆盖。
- 保存状态的圆点用 `--green`；改动提示的图标用 `--green`。
- 停止输入 800ms 后自动保存；选中文字时才显示格式工具条；`/` 打开 300px 宽的单列菜单。

## SSH 节点工作台

节点连接后左侧显示 SSH 终端与文件，右侧显示 Agent Chat，并自动准备使用本机模型配置的隔离会话。无需远端安装 pi 或再次点击启动。准备期间显示状态，输入框常驻；准备完成后即可发送。失败时在右侧显示错误与重试入口，SSH 终端保持可用。正文按用户消息、助手回复、思考与工具结果展示；发送确认后才清空草稿，保留排队/纠正、停止、模型选择及新对话。远端目录在会话准备前或重开时设置，工具明确作用于当前节点；左侧页脚说明手动终端与右侧命令结果的区别。关闭 Agent 后保留重新打开入口，不立即自动重开。

Wiki 插入菜单在输入触发浏览器自动滚动时继续跟随可见光标定位；光标离开视口或窗口改变尺寸时关闭。菜单自身的列表滚动不关闭菜单。

### Wiki 模型选择（#50）

Wiki 对话面板和展开的底部输入卡片复用聊天的模型、思考强度选择器。选择器位于输入区独立一行，菜单向上展开；会话准备、断线和项目切换期间禁用，避免修改旧会话。

### 节点工作台左右分栏（#48）

节点连接后左侧常驻 SSH 终端与文件，右侧常驻本机 Agent 经 SSH 操作节点的对话；不再通过页签互相隐藏。窄屏改为上下排列，保留两侧可见和独立滚动。连接成功自动准备 Agent；连接本身不安装软件、不调用模型。本地主聊天与各节点对话、工具及历史彼此隔离。

### 文件树参考图版

文件标题栏下提供「搜索文件」入口（Cmd/Ctrl+P），只搜索当前工作区文件；Cmd/Ctrl+K 保留全局搜索。根目录显示加粗项目名，可整体折叠。目录行使用系统无衬线字体、32px 行高、中性线框文件夹图标及每层 18px 缩进；改动目录右侧用浅黄色数量标记。保留新建、刷新、隐藏文件开关、附件操作及下方任务面板；键盘上下移动和左右展开收起包括根节点。

消息输入卡片内部 textarea 不显示独立的蓝色焦点描边，沿用外层卡片边框反馈；按钮和其他控件保留键盘焦点。

### UI/UX Pro Max 全页优化

范围和验证进度见 [全页面优化与验收](ui-ux-polish.md)。设置在 640px 以下采用顶部带图标与文字的横向导航，内容区占满宽度，选中项有 `aria-current`。弹窗进入时焦点置于可操作控件，Tab/Shift+Tab 留在当前最上层弹窗内，关闭恢复触发入口；按钮保留可见焦点。输入区仍不恢复用户要求去掉的内层蓝框。小屏弹窗输入文字 16px，避免移动浏览器聚焦时自动放大。

Git 工作台在 700px 以下将改动/历史列表放在 diff 上方，各自滚动，避免手机上两列挤压。分支与提交输入保留可访问名称，错误使用 alert。触屏终端工具按钮、Git 行及节点主要操作最小 44px；手机表单输入 16px，长路径可换行。

手机（≤760px）打开 Wiki 文档默认先显示正文，聊天收起为底部输入入口，可通过顶栏「对话」或 Cmd/Ctrl+J 展开；桌面仍默认展开聊天。切换文档重新按当前窗口宽度选择初始布局；单纯缩放窗口不覆盖用户手动展开/收起。手机文档正文为 16px，标题 28px，左右留白 20px。
